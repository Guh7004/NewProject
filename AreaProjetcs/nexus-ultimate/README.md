# NEXUS / Q1 HE — Ultimate Concept
Landing page conceitual premium inspirada no Keychron Q1 HE.

## Rodar
Abra `index.html` com Live Server no VS Code. Internet é usada apenas para Google Fonts e GSAP via CDN.

## Estrutura
- `index.html` — narrativa e conteúdo
- `style.css` — direção visual/responsividade
- `script.js` — animações GSAP + ScrollTrigger
- `assets/` — renders conceituais gerados para a campanha

## Observação
Os renders são conceituais e não são fotografias oficiais da Keychron. O CTA final aponta para a página oficial do produto. Não use estes renders como representação contratual exata do produto em uma loja real sem substituí-los por material oficial/licenciado.
